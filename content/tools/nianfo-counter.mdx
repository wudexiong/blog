# 念佛计数器

一个简洁的在线念佛计数工具，帮助净土同修记录每日念佛数量。

## 功能特点

- **简洁界面**：无干扰的计数界面
- **数据保存**：自动保存计数记录
- **目标设定**：可设定每日念佛目标
- **历史统计**：查看历史念佛记录

## 使用方法

1. 打开工具页面
2. 点击计数按钮或按空格键计数
3. 数据会自动保存到本地

## 使用建议

建议每日设定一个固定的念佛数量目标，如：

- 初学者：每日1000声
- 进阶者：每日3000声
- 精进者：每日10000声

> 一声阿弥陀佛，消八十亿劫生死之罪。

## 技术实现

本工具使用现代Web技术构建：

- React + TypeScript
- LocalStorage 数据持久化
- 响应式设计
